# Coreforge - Game Design Document

## Game Title: Coreforge

**Tagline:** Build. Defend. Break the Core.

## Core Loop
- Explore star systems on a galaxy map
- Fly your modular ship in real-time 2D space
- Mine asteroids for resources
- Defend against waves of AI drones
- Build and upgrade ship modules
- Progress to the final AI core battle

## Key Features
- Deep modular ship building
- Real-time combat and mining
- Procedural sectors
- Resource management and progression

## Current Development Phase
Modular ship system implemented.

We will continue adding enemy drones, resources, galaxy map, etc.
